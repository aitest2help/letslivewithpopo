# Let’s Live with Popo — onboarding demo

A public first-review demo of Chapters 1 and 2, Indonesian by default with English selectable. Main content is visible by scrolling. Each Listen button reads only its own part using the device/browser voice; it stops at the end. No autoplay or whole-chapter narration.

## Visibility and scope

Published without password protection at the owner’s explicit request on 17 November 2026. Text and the selected demo photographs are publicly accessible. Noindex is an indexing instruction, not access protection. This is not a final approved six-chapter guide for a new hire. Do not add private medical/contact/source records here before an agreed privacy solution.

Only the reader-facing demo is included. No applicant page, raw Lis feedback, prescription/medicine register, database, WhatsApp integration, generated narration, authentication or source tools. The applicant site is a separate repository and is not modified by this deployment.

## Hosting and versions

GitHub Pages serves main at the repository root. No build step; .nojekyll disables Jekyll processing. All asset/module/data paths are relative to the project URL. Changes are ordinary Git commits. Preserve an earlier commit/tag and restore through a new forward commit if rollback is requested; never force-push.

Indonesian voice availability depends on the phone/browser and may require installing a matching voice. A missing voice is explained rather than replaced with English. Actual audio needs a phone check.
